# Система управления зоопарком 
(учебный проект Zerocoder "Программист на Python с нуля")

Это простая система управления зоопарком на Python, демонстрирующая концепции объектно-ориентированного программирования, такие как наследование, композиция и полиморфизм. Система позволяет моделировать животных и сотрудников зоопарка и предоставляет функциональность для управления животными и персоналом в зоопарке.

## Особенности

- **Иерархия классов животных**: Система поддерживает различные типы животных с определённым поведением, таким как издавание звуков и еда.
- **Управление зоопарком**: С помощью композиции класс `Zoo` может хранить информацию о животных и сотрудниках, а также добавлять их в зоопарк.
- **Типы сотрудников**: В системе есть два типа сотрудников: `ZooKeeper` (смотритель) и `Veterinarian` (ветеринар), каждый из которых имеет специфические методы, такие как кормление и лечение животных.
- **Звуки и питание**: Каждое животное может издавать звук и есть, и это отображается в зависимости от типа животного.

## Структура классов

### Класс Animal

Класс `Animal` является базовым для всех типов животных и предоставляет общие атрибуты (`name`, `age`) и методы (`make_sound()`, `eat()`).

### Производные классы животных

- `Bird`: Представляет птицу. Переопределяет методы `make_sound()` и `eat()` с поведением, специфичным для птиц.
- `Mammal`: Представляет млекопитающее. Переопределяет методы `make_sound()` и `eat()` с поведением, специфичным для млекопитающих.
- `Reptile`: Представляет рептилию. Переопределяет методы `make_sound()` и `eat()` с поведением, специфичным для рептилий.

### Класс Zoo

Класс `Zoo` содержит информацию о животных и сотрудниках зоопарка. Он предоставляет методы для добавления животных и сотрудников.

- **Методы**:
  - `add_animal(animal)`: Добавляет животное в зоопарк.
  - `add_staff(staff_member)`: Добавляет сотрудника в зоопарк.

### Классы сотрудников

- `ZooKeeper`: Сотрудник зоопарка, который может кормить животных.
  - **Метод**:
    - `feed_animal(animal)`: Кормит указанное животное.

- `Veterinarian`: Сотрудник зоопарка, который может лечить животных.
  - **Метод**:
    - `heal_animal(animal)`: Лечит указанное животное.

## Пример использования

```python
# Создаем зоопарк
zoo = Zoo()

# Создаем животных
bird1 = Bird("Воробей", 2)
mammal1 = Mammal("Корова", 5)
reptile1 = Reptile("Уж", 3)

# Добавляем животных в зоопарк
zoo.add_animal(bird1)
zoo.add_animal(mammal1)
zoo.add_animal(reptile1)

# Создаем сотрудников зоопарка
zookeeper = ZooKeeper()
veterinarian = Veterinarian()

# Смотритель кормит животных
zookeeper.feed_animal(bird1)

# Ветеринар лечит животных
veterinarian.heal_animal(mammal1)

# Издаем звуки животных и показываем, как они едят
animals = [bird1, mammal1, reptile1]
for animal in animals:
    animal.make_sound()
    animal.eat()
